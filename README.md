# Acquisition-grade template

This repository is a minimal acquisition-grade template intended for Microsoft-facing projects.

Sections:
- Purpose
- Quick start
- Security and reporting

Purpose
-------
Provide a secure, well-documented starting point for projects targeting acquisition with Microsoft.

Quick start
-----------
1. Clone the repo:
   git clone https://github.com/worthwyl2022-cloud/acquisition-grade-template.git
2. Create a feature branch, make changes, run tests, and open a pull request.

Security
--------
See SECURITY.md for vulnerability reporting and policies.
