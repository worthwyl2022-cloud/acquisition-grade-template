Thank you for contributing!

Please follow these guidelines to help maintain code quality and security:

- Fork the repo and create a feature branch.
- Add tests for new behavior and run the test suite locally.
- Keep changes small and focused.
- Ensure no secrets are included in commits.

Pull request checklist
- [ ] My changes follow the project's coding standards
- [ ] I have added tests that prove my fix is effective or that my feature works
- [ ] I have added necessary documentation (README or inline docs)
